## AI assistance

GitHub doesn't allow AI models to be added as real accounts/collaborators, so
their help is credited here instead:

- **Claude** (Anthropic) — code and docs assistance
- **Grok** (xAI) — code and docs assistance

If you want AI involvement visible in the actual git history, you can add a
co-author trailer to relevant commits instead of (or in addition to) this
file, e.g.:

```
git commit -m "Add graph view zoom controls

Co-authored-by: Claude <noreply@anthropic.com>
Co-authored-by: Grok <noreply@x.ai>"
```

GitHub will then show these as co-authors on the commit and on your profile's
contribution graph.
